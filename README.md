# Handoff: أمي — مدرّب القراءة العربية بالصوت

## Overview
تطبيق جوال (Android-first) يعلّم المستخدمين القراءة العربية عبر الصوت: تظليل متزامن، تقليد صوتي، قراءة مستقلة، ومواقف حياتية. يحتوي على مسارين تعليميين منفصلين يُختاران تلقائيًا بعد اختبار قراءة قصير:
- **مسار "الطلاقة والثقة"**: لكبار السن/ضعاف القراءة الناطقين بالعربية — تظليل حرف حرف، نبرة هادئة وأنيقة بلا رسوم كرتونية.
- **مسار "تعلّم من الصفر"**: لغير الناطقين بالعربية — تظليل كلمة كلمة، أسلوب أكثر تفاعلية وتحفيزًا (نقاط/سلاسل أيام).

## About the Design Files
الملفات هنا **مرجع تصميمي مبني بـ HTML** — نموذج تفاعلي (prototype) يوضح الشكل والسلوك المقصودين، وليس كودًا للنسخ المباشر. المطلوب هو **إعادة بناء هذا التصميم** في بيئة التطوير الفعلية (React Native / Flutter / iOS-Android native، أو PWA) باستخدام أنماط وأدوات تلك البيئة. إن لم توجد بيئة بعد، اختر الأنسب (React Native أو Flutter موصى بهما لتطبيق يعمل offline-first على منصتين).

`design_reference.html` يعمل فقط داخل منصة التصميم الأصلية (يعتمد على `support.js` كمحرك تشغيل خاص بها) — **لن يعمل كملف HTML مستقل أو على استضافة ثابتة مثل GitHub Pages**. استخدمه فقط كمرجع بصري/سلوكي (افتحه في المتصفح عبر المنصة الأصلية، أو استخرج البنية والقيم يدويًا).

## Fidelity
**High-fidelity**: ألوان، مسافات، خطوط، وتفاعلات محددة نهائيًا. أعد بناء الواجهة بدقة باستخدام مكتبات/نظام التصميم الخاص بالكودبيس المستهدف.

## أهم قرار تصميمي: فصل المسارين
دمج الفئتين في مسار واحد خطأ متعمّد التجنّب: صعوبة غير الناطق لغوية-صوتية (تعلّم الحروف والأصوات من الصفر)، بينما صعوبة كبير السن الناطق مرتبطة بفك الرموز والطلاقة والثقة بالتقنية — وليس بفهم اللغة. لذلك التفرّع يظهر في: طريقة التظليل (حرف/كلمة)، النبرة، ودرجة التحفيز الحركي (gamification)، لا في المحتوى نفسه بالضرورة.

## Screens / Views

### 1. Splash (شاشة البداية)
- خلفية `#FAF5EA`، توسيط عمودي/أفقي كامل.
- شعار: مربع 88×88px، `border-radius:24px`، خلفية `#1F6B63`، أيقونة كتاب بيضاء (سطر SVG stroke).
- عنوان "أمي" — 30px/800/#26333B.
- وصف فرعي 16px/#5E6C72، `max-width:280px`، `line-height:1.7`.
- زر "ابدأ الآن": عرض كامل حتى 280px، ارتفاع 58px، `border-radius:16px`، خلفية `#1F6B63`، نص أبيض 18px/700.
- ملاحظة صغيرة أسفل الزر 13px/#8A968C.

### 2. اختبار قراءة سريع (Test)
- بلا top bar. عنوان 20px/800 ووصف 14px/#5E6C72.
- بطاقة نص الاختبار: خلفية بيضاء، حدود `#E4D9C2`، `border-radius:18px`، نص 26px/700 وسط.
- ثلاث حالات ميكروفون:
  - **البداية**: زر دائري 96px خلفية `#1F6B63` بأيقونة ميكروفون.
  - **تسجيل**: نفس الزر مع `animation:pulseMic 1.6s infinite` (نبضة `box-shadow` بلون كهرماني `rgba(180,128,46,…)`)، نص "...يستمع الآن" بلون `#B4802E`، زر ثانوي "انتهيت من القراءة" (outline).
  - **تحليل**: مؤشر تحميل دائري (spinner) بحدود `#E4D9C2` وأعلى `#1F6B63`، نص "لحظات... نحضّر لك البداية الأنسب".
- بعد 1.5 ثانية ينتقل تلقائيًا لشاشة اقتراح المسار.

### 3. اقتراح المسار (Track Suggest)
- بطاقة المسار المقترح: حدود ملونة 2px بلون المسار (`accent`)، أيقونة قلب داخل مربع 48px بخلفية "soft" من نفس اللون، عنوان 17px/800، وصف 14px، زر تأكيد بلون المسار ملء.
- فاصل "أو اختر بنفسك".
- بطاقة المسار الآخر بنفس الشكل لكن outline فقط.
- ألوان المسارات:
  - **الطلاقة والثقة (elder)**: accent `#B4802E`, accent-soft `#F2E6CC`
  - **تعلّم من الصفر (nonnative)**: accent `#D1603A`, accent-soft `#F8E1D6`

### 4. الرئيسية (Home)
- ترحيب + مؤشر سلسلة الأيام (badge بخلفية soft للون المسار).
- بطاقة "الدرس التالي": وسم تصنيف، عنوان 19px/800، زر "متابعة القراءة" (أخضر أساسي `#1F6B63`).
- شبكة 2×1: "تقليد الصوت" و"قراءة مستقلة" (بطاقات outline).
- بطاقة عريضة "مواقف من الحياة اليومية" بخلفية soft للمسار.
- قائمة "دروس مقترحة" (بطاقات صف واحد برقم + عنوان + سهم).

### 5. الدروس (Lessons tab)
قائمة كاملة بنفس نمط بطاقة الدرس، مع زر تشغيل دائري أخضر بدل السهم.

### 6. مواقف الحياة اليومية (Scenarios tab)
شبكة 2×2، كل بطاقة: أيقونة 44px بخلفية soft للمسار، عنوان 13px/700 وسط. أمثلة: قراءة علبة دواء، رسالة نصية، لافتة شارع، قائمة طعام.

### 7. حسابي (Profile)
- بطاقة حجم الخط: 3 أزرار حجم (segmented)، ومعاينة حية "نموذج للقراءة" بخلفية `#F1EAD9`.
- بطاقة تبديل المسار يدويًا (زرّان مع حالة محددة).
- بطاقة دعم بخلفية `#F1EAD9`.

### 8. مشغّل الدرس (Lesson Player) — قلب التظليل المتزامن
- مفتاح تبديل (segmented control) بين "تظليل حرف حرف" و"تظليل كلمة كلمة" — الافتراضي حسب المسار (حرف للطلاقة، كلمة لغير الناطقين).
- بطاقة نص كبيرة (28px×مقياس الخط) تعرض الرموز (حرف أو كلمة) كعناصر `<span>` منفصلة؛ الرمز النشط أثناء التشغيل يأخذ خلفية+لون accent للمسار مع `border-radius:6px`.
- أزرار: إعادة (دائري outline)، تشغيل/إيقاف (دائري 72px أخضر، أيقونة تتبدل play/pause).
- في النموذج، التزامن مبني على `setInterval` بسيط (150ms/حرف، 480ms/كلمة) — **في التطبيق الحقيقي يجب استبداله بتوقيتات محاذاة صوتية دقيقة (forced alignment) لكل حرف/كلمة مطابقة لملف الصوت الفعلي**.
- أسفل: زر "قلّد الآن" (بلون المسار) وزر "قراءة مستقلة" (outline).

### 9. تقليد الصوت (Mimicry)
- بطاقة نص الدرس، زر "استمع للنموذج" (outline مع أيقونة play).
- 3 حالات: idle (زر ميكروفون بلون المسار) → recording (نبضة + أشرطة موجة متحركة `waveBar` مختلفة السرعات) → recorded (علامة صح خضراء `#3F8F5F`، زرّي "استمع لصوتي"/"استمع للنموذج" جنبًا لجنب، ثم "أعد المحاولة"/"أنهيت، التالي"). **بدون تقييم آلي دقيق للنطق — مقارنة صوتية سمعية فقط** كما طلب المستخدم.

### 10. القراءة المستقلة (Fluency)
- فقرة بلا أي تظليل، يقرأها المستخدم بصوته بحرية.
- حالات: idle (زر "ابدأ القراءة") → reading (عدّاد وقت + زر "أنهيت القراءة" بلون كهرماني `#B4802E`) → done (علامة صح، مدة القراءة، زر استماع للتسجيل، عودة للرئيسية).

### 11. تفاصيل موقف حياتي (Scenario Detail)
- صورة/image-slot أعلى الشاشة (`ratio` حر، `height:150px`) — تحتاج صورًا حقيقية (علبة دواء، رسالة، لافتة، قائمة طعام) بدل الحشو.
- نص الموقف بتظليل كلمة-كلمة عند الضغط "استمع وتابع القراءة".

## Interactions & Behavior
- التنقل بين الشاشات عبر state machine بسيط (`screen` + `activeTab`)، مع سجلّ "الشاشة السابقة" للرجوع الصحيح.
- زر الرجوع في الـ top bar يظهر فقط في الشاشات الفرعية (الدرس، التقليد، القراءة المستقلة، تفاصيل الموقف).
- شريط سفلي (bottom nav) من 4 عناصر: الرئيسية، الدروس، المواقف، حسابي — يظهر فقط في الشاشات الرئيسية الأربع.
- تكبير/تصغير الخط عالمي عبر زرّي "أ-"/"أ+" في top bar (3 مستويات: 0.85×, 1×, 1.2×) — يؤثر على حجم نص الدرس بشكل خاص.
- Animations: `pulseMic` (نبضة تسجيل)، `waveBar` (أشرطة صوت أثناء التقليد) — CSS keyframes بسيطة، مدتها 0.5–1.8s.

## State Management (من النموذج، للاسترشاد فقط)
حقول الحالة الأساسية المطلوبة في التطبيق الحقيقي:
- `userId`, `selectedTrack` ('elder' | 'nonnative')
- `currentStreak`, `lastActiveDate`
- `lessonProgress[]` (lessonId → completed/score/attempts)
- `fontScalePreference`
- سجل التسجيلات الصوتية للمستخدم (روابط ملفات، ليس الصوت نفسه في الحالة)

## احتياجات التفعيل الفعلي (Backend/Infra — أهم قسم لهذا الـ handoff)
النموذج الحالي **بلا حفظ بيانات حقيقي وبلا صوت حقيقي** (المؤقتات وهمية). لتشغيله كتطبيق فعلي:

1. **قاعدة بيانات + مصادقة**: Firebase/Supabase/PostgreSQL، تسجيل دخول برقم الجوال (الأنسب للفئة المستهدفة).
2. **الصوت**:
   - TTS عربي عالي الجودة لتوليد "صوت النموذج" لكل نص.
   - تسجيل صوت حقيقي (MediaRecorder / native audio APIs) وتخزينه.
   - تظليل متزامن حقيقي يحتاج **forced alignment** (توقيت دقيق لكل حرف/كلمة مطابق للصوت) بدل المؤقت الوهمي في النموذج.
   - مقارنة الصوت: سمعية بسيطة كما هو مصمم، أو تقييم آلي للنطق (أعقد وأغلى تقنيًا، خدمة تعرف كلام عربي).
3. **بنك محتوى حقيقي**: دروس ومواقف حياتية (نصوص + ملفات صوتية) مراجعة من مختص لغوي/تربوي، بدل الأمثلة القليلة الحالية.
4. **تطبيق فعلي**: React Native أو Flutter (offline-first — الفئة المستهدفة قد لا تملك اتصالًا مستقرًا) أو PWA، مع خادم خلفي يربط كل ما سبق.

## Design Tokens
- ألوان أساسية: خلفية `#EDE7D8` (خارج الجهاز) / `#FAF5EA` (داخل الشاشة)، بطاقات بيضاء `#fff` بحدود `#E4D9C2`، نص أساسي `#26333B`، نص ثانوي `#5E6C72`، نص خافت `#8A968C`، خلفية خفيفة `#F1EAD9`.
- أخضر أساسي (فعل رئيسي/شعار): `#1F6B63`.
- ألوان المسارات: كهرماني `#B4802E`/`#F2E6CC` (الطلاقة)، مرجاني `#D1603A`/`#F8E1D6` (تعلّم من الصفر).
- أخضر نجاح: `#3F8F5F`.
- خط: Cairo (400–800)، عربي RTL بالكامل (`dir="rtl"`).
- زوايا: 12–24px حسب حجم العنصر. لا ظلال قوية — حدود رفيعة فقط.
- الأزرار: ارتفاع أدنى 44–58px (متوافق مع متطلبات سهولة اللمس لكبار السن).

## Assets
لا صور فعلية — أماكن نائبة (`image-slot`) لأربعة مواقف حياتية (علبة دواء، رسالة نصية، لافتة شارع، قائمة طعام) تحتاج صورًا حقيقية عند التنفيذ. الأيقونات كلها SVG مرسومة يدويًا (بلا مكتبة أيقونات خارجية).

## Files
- `design_reference.html` — التصميم الكامل (كل الشاشات ومنطق التنقل التجريبي).
- `android-frame.jsx` — إطار جهاز Android (مرجع بصري فقط، ليس للاستخدام المباشر في التطبيق الحقيقي).
- `image-slot.js`, `support.js` — أدوات تشغيل خاصة بمنصة التصميم؛ غير مطلوبة في الكودبيس النهائي.
